# EarthAware — Global Warming Awareness Website

A clean, responsive educational website about global warming with:
- Hero landing section
- What global warming is
- Main causes
- Environmental impacts
- Practical solutions
- Interactive 10-question quiz with score
- Responsive mobile navigation
- Modern professional styling

## Run
Open `index.html` in a modern browser.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design and styling
- `script.js` — interactive quiz and mobile menu

## Note
The site uses remote Unsplash image URLs and Google Fonts. Internet access is required for those external assets. The core HTML/CSS/JS works locally without a server.
